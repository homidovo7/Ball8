# Magic 8 Ball

Небольшое приложение на React и Vite. Задай вопрос, нажми кнопку и получи случайный ответ от шара.

## Запуск на компьютере

Установи [Node.js](https://nodejs.org/), скачай или склонируй проект, открой его папку в терминале и выполни:

```bash
npm install
npm run dev
```

Открой в браузере адрес, который покажет Vite.

## Публикация на GitHub

1. Создай новый репозиторий на [GitHub](https://github.com/new). Для ссылки, которой можно поделиться, выбери **Public**.
2. Не добавляй на GitHub файлы `README`, `.gitignore` или лицензию при создании репозитория: они уже есть в проекте.
3. Скопируй адрес созданного репозитория. В терминале, открытом в папке проекта, выполни команды ниже, заменив адрес на свой:

```bash
git add .
git commit -m "Создал Magic 8 Ball"
git branch -M main
git remote add origin https://github.com/ТВОЙ-ЛОГИН/ИМЯ-РЕПОЗИТОРИЯ.git
git push -u origin main
```

После этого отправь другим ссылку на страницу репозитория. Они смогут скачать код и запустить его командами из раздела выше.

## Файлы проекта

- `src/App.jsx` — приложение и выбор случайного ответа.
- `src/App.css` — оформление.
- `src/main.jsx` — запуск React.
- `index.html` — HTML-страница приложения.
